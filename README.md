# API Nota Fiscal

Uma API desenvolvida com Node.js, Express e TypeScript.

## Sobre o Projeto

Esta API permite realizar operações:

- Criar dados em diferentes tabelas.
- Listar dados de diferentes tabelas.
- Listar dados por ID de diferentes tabelas.
- Atualizar dados por ID em diferentes tabelas.
- Remover dados por ID de diferentes tabelas.
- Guarda informações em diferentes tabelas.
- É organizado por tabelas que possuem diferentes dados (Ex: Nota,Estoque,Carro,Cliente e Vendedor).

Projeto criado para estudos de desenvolvimento backend utilizando TypeScript e Express.
